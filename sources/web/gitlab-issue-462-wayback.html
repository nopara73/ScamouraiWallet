Coordinator Fee Address Reuse

For Whirlpool coinjoins, the coordinator collects their fee in each preceding tx0 transaction with its own dedicated output. The value of the fee output implicitly distinguishes it from the change and the mixing amounts, so there is no presumption of privacy as to which entity controls it.

However, the coordinator has been reusing receive addresses in some instances to collect this fee. The most used address I noticed during research was bc1qhyls4wa9hlpvwa0y980mz0qhjyfhjkf4t5v6lh which was used for 37 transactions.

This has happened both recently as well as in the past, reuse has occurred since at least 2022:

Unconfirmed - https://mempool.space/tx/5b22ceee9357f8049b555a8938f79c22ccef323ec9ce9976a2a9e9124c437f34

Block height 810549 - https://kycp.org/#/05a40086c4e92bd0ed35681ac267dfbd9aea9f690a63c817cda41a2c12b95dee

Block height 756501 - https://kycp.org/#/075224a5f39388188daea9ab97cbe507bf807ef162221d2d3e5890a6755e1374
